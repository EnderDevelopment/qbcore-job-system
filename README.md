# QBCore Job System

A versatile job system for QBCore FiveM servers.

## Features

- Job-specific blips on the map
- Regular payments for active job members

## Requirements

- QBCore framework
- FiveM server

## Installation

1. Download the script
2. Place it in your `resources` folder
3. Add `start qbcore-job-system` to your `server.cfg`

## Usage

1. Players with the 'jengi' job will see job-specific blips on the map
2. Players will receive regular payments while on the job

## Configuration

Edit the `config.lua` file to customize job details, payment amounts, and intervals.
